# Go-Agnostic

A library to make it easy to support multiple Minecraft versions with a single mod.

***This is designed for utility mods, not content mods. The likes of indepth GUIs, TEs, etc will never be supported.***

For example usages, see Advanced Backups, Server Started!, and ModpackInfo.

Supported features:
- Toasts (1.12+)
- Commands
- Many events
- Actual mod registration of course


Supported modloaders:
- Forge (1.7.10-1.20.6)
- Fabric (1.18+)
- Neoforge (1.20+)
