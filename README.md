# Go!Agnostic

A library to make it easy to support multiple Minecraft versions with a single mod.

***This is designed for utility mods, not content mods. The likes of indepth GUIs, TEs, etc will never be supported.*** (though I may consider a way to have SOME sort of gui)

This is still very much work in progress.

# Usage and Features

`tests` contains a test of every single Minecraft-related feature Go!Agnostic offers.

Later down the line, I will migrate many mods to it. Advanced Backups, Server Started!, Polychat3 and ModpackInfo will be linked here when they use Go!Agnostic.

Currently supported features:
- Lifecycle events
- Tick events
- Player join / leave events and playerlist
- Commands, including permissions, arguments and subcommands

Planned features: 
- Basic networking
- Deeper server interaction (such as modlist, save control, command execution, etc)
- Toasts (1.12+)
- Some form of basic gui?
- Possibly an extension system

Got a request for a version or feature to support? Let me know!

More extensive documentation to come!
